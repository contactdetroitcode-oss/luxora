# LUXORA — Luxury Perfume Store

A premium e-commerce website dedicated to luxury fragrances, featuring an elegant visual identity and a refined shopping experience.

🌐 **Live Demo:** https://contactdetroitcode-oss.github.io/luxora/

## Overview

LUXORA is a front-end e-commerce project designed to showcase luxury perfumes through a modern, elegant, and user-friendly interface.

## Features

* Premium luxury-inspired design
* Product catalog and product details
* Shopping cart
* Checkout interface
* Responsive layout for different screen sizes
* Interactive user experience

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* GitHub Pages

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/contactdetroitcode-oss/luxora.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

## Project Structure

* `index.html` — Homepage
* `shop.html` — Product catalog
* `product.html` — Product details
* `cart.html` — Shopping cart
* `checkout.html` — Checkout page
* `style.css` — Website styling
* `script.js` — Main JavaScript functionality
* `products.js` — Product data
